Three-layer Diff tree, key sequence, hits, and source backfills.

Protocol

Reads try JSON first, then pickle only when JSON decoding fails. JSON and pickle keys may coexist; the envelope identifies the actual protocol, so a reader downgrades to the writer's format instead of overwriting it.

Root/index/prefix

Root and index are siblings of an explicit :node: prefix, avoiding root-key false positives during child scans. Normal reads use the maintained index; if it is lost, the first reader pays one scan and rewrites it.

Concurrent misses

LocalStore deduplicates the same key in-process; RedisStore owns distributed same-key locking. Parent and child are different keys and may both call their source, while duplicate same-key writes never overwrite the winner.
